# Time Machine

Time Machine is a history and bookmarks cleaner by A A Hasnat and HNE Technologies. It helps users delete unwanted browsing history and bookmark entries using keywords or host-pattern matching, with preview-first deletion flows.

Links:

- GitHub: https://github.com/deadsec07/time-machine
- Main site: https://hnetechnologies.com/
- Creator profile: https://deadsec07.github.io/

## Features
- Delete Chrome history by keyword or host pattern
- Delete bookmarks by keyword or host pattern
- Preview before delete
- Minimal and local-first utility workflow
